Accessible corporate theme for Edgepoint Internets Solutions Ltd.

== Installation ==

1. Install and activate Edgepoint Core first.
2. Upload the Edgepoint theme ZIP through Appearance > Themes > Add New.
3. Activate the theme.
4. Configure menus and verify all business details under Settings > Edgepoint details.
5. Keep preview mode enabled until all placeholder contact information is replaced.
