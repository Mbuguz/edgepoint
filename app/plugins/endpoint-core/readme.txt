Portable content, enquiry, business settings, and SEO foundations for Endpoint Internet Solution.

== Description ==

Endpoint Core registers structured service, product, project and industry content,
provides a secure quotation-request shortcode, stores verified business identity,
and supplies conservative metadata when no dedicated SEO plugin owns it.

Use [endpoint_quote_form] on the Get a Quote page.

Preview mode is enabled by default. It adds noindex directives and prevents form
submissions from being stored or delivered while placeholder details remain.

== Installation ==

1. Upload and activate the plugin.
2. Open Settings > Endpoint details.
3. Replace every placeholder with verified information.
4. Add a private quote recipient and test authenticated email delivery.
5. Disable preview mode only after the release checklist passes.

== Privacy ==

In production mode, the quote form stores contact details and requirements as
private WordPress enquiry records. Site administrators must define retention,
access, privacy-notice and deletion procedures before collecting personal data.
